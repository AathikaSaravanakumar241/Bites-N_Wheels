# Contributing to Bites-N-Wheels

Thanks for your interest in contributing.

## Contribution workflow

1. Fork this repository.
2. Create a branch from `main` in your fork.
3. Make your changes and test them locally.
4. Push your branch to your fork.
5. Open a pull request targeting `main` in this repository.

Direct pushes to `main` are not part of this contribution workflow.

## Pull request review

Pull requests are reviewed by the repository owner or approved maintainers before merge.
